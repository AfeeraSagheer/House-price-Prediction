# House-price-Prediction
# House Price Prediction - Exploratory Data Analysis & Machine Learning

## Project Overview
This project focuses on analyzing a Housing Price dataset and building a machine learning model to predict house prices using different housing features.

The project includes:
- Exploratory Data Analysis (EDA)
- Data visualization
- Data preprocessing
- Feature analysis
- Machine learning model training
- Model evaluation

The main goal is to understand how different housing attributes affect house prices and build a regression model for prediction.

---

# Dataset Information

The dataset contains housing-related information used for predicting house prices.

## Dataset Columns

| Column Name | Description |
|---|---|
| price | Price of the house |
| area | Area of the house |
| bedrooms | Number of bedrooms |
| bathrooms | Number of bathrooms |
| stories | Number of stories/floors |
| mainroad | Whether house is connected to main road |
| guestroom | Availability of guest room |
| basement | Availability of basement |
| hotwaterheating | Hot water heating availability |
| airconditioning | Air conditioning availability |
| parking | Number of parking spaces |
| prefarea | Whether house is in preferred area |
| furnishingstatus | Furnishing condition of house |
